# AI Contribution Policy

This project **does not** allow any type of contribution to be made with the assistance of AI tools.

This includes, but is not limited to, code generation, documentation, issue creation, and any other content that is created with the help of AI. All contributions must show signs of human authorship and be the result of the contributor's own work.

Where it is suspected that AI has been used to generate content, the contribution will be rejected unless the contributor can prove otherwise.

## Summary

- AI must not be used for any contributions
- Contribution guidelines must still be followed
- Abuse, such as spam, scams, or malicious content, is not allowed

This policy is based on the [AI Disallowed policy, version 1.0.0](https://ai-policy.dev/policies/ai-disallowed/1.0.0) from 2026-09-20. Read more about this and other AI contribution policies on [ai-policy.dev](https://ai-policy.dev/).
